### Quick Install Inside KiCad
- Install our official KiCad Plugin: **[chipdocs/chipdocs-kicad-plugin](https://github.com/chipdocs/chipdocs-kicad-plugin)**
- Or clone this repo and add `kicad/chipdocs.pretty` + `kicad/symbols/` in **Preferences → Manage Footprint/Symbol Libraries** ([step-by-step guide](https://chipdocs.org/guides/import-kicad-8-9-footprint-symbol-3d-step)).
- Using Fusion 360 / EAGLE, Altium, OrCAD, PADS or DipTrace? See **[github.com/chipdocs](https://github.com/chipdocs)** for dedicated repos!
